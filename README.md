# Clinic Demo — Ivory Dental Studio

Futuristic dental clinic demo with an interactive Three.js tooth, Indian patient imagery, responsive layouts, and a three-second intro.

## Deploy on Vercel

Import this repository. Framework preset: Other. No build command is needed. The included vercel.json sets the output directory to dist.

## Local preview

Run `python -m http.server 8000 --directory dist` and open http://localhost:8000.

## Demo content

The clinic and testimonials are fictional. Images are AI-generated. Appointment requests are local previews and are not sent or stored.
