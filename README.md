# Clinic Demo — Ivory Dental Studio

Futuristic dental clinic demo featuring an interactive Three.js tooth, Indian patient imagery, responsive layouts, and a three-second intro.

## Hosting

Static website. Serve the `dist` directory. For Vercel, import this repository; `vercel.json` sets the output directory. No build command or dependencies are required.

## Notes

The clinic and testimonials are fictional. Images are AI-generated. Appointment requests are local demo previews and are not submitted or stored.
